# 通用混合检索设计

## 目标

提升普通文本问答的召回率：当语义相似度受日期、实体等高频信息干扰时，包含用户关键字的文本仍应进入重排候选。

## 范围

- 保持现有 Milvus 向量检索、父记录展开和交叉编码器重排。
- 不引入任何行业词典、财务字段、特定实体或文档类型规则。
- 修复异步函数被同步计时装饰器包装后，日志只记录协程创建时间的问题。

## 方案

检索器先从 Milvus 取 200 个语义候选。在这些候选内，基于通用的中英文词项重合度额外选择词项候选；两组候选按内容和记录元数据去重后，由现有 reranker 统一排序。中文词项使用连续汉字双字片段，英文和数字使用连续字母数字片段，因此不依赖任何领域术语。

候选池始终有限，避免每次查询扫描整个 collection；父记录展开仍只发生在最终命中的记录上。

`time_consume` 根据被装饰函数是否为协程函数分别返回同步或异步包装器。异步包装器在 `await` 前后采样时间，记录真实执行耗时。

## 验证

- 测试证明低位语义候选只要包含更多查询词项，仍会进入重排并最终返回。
- 测试证明异步函数日志记录跨越 `await` 的耗时。
- 使用现有 `/search` 接口验证“比亚迪营业额”查询返回包含 `602,315` 的上下文。
